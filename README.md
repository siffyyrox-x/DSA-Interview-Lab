# DSA Interview Lab

A visual and structured **120-hour Data Structures & Algorithms roadmap in Python** for coding interview preparation.

## Features

- 23 complete DSA topics
- 205 curated LeetCode problems
- 40-day study plan
- Visual algorithm explanations
- Python templates
- Brute-force → optimal walkthroughs
- Complexity and pattern cheat sheets
- Topic and problem progress tracking
- Daily study streak
- Dark, paper, and calm themes
- Fully responsive and lightweight

## Topics

Arrays, Hashing, Two Pointers, Sliding Window, Stacks, Queues, Linked Lists, Recursion, Backtracking, Sorting, Binary Search, Trees, BST, Heaps, Graphs, Shortest Paths, Greedy, Dynamic Programming, Tries, Bit Manipulation, and more.

## Run

Open:

```text
dist/index.html
```

or serve locally:

```bash
python -m http.server 8000 -d dist
```
